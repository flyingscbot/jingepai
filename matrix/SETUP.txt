----

  浏览器 ──authorize/登录──► 127.0.0.1:1000（金格 Flask）

                 │

                 ▼

         FluffyChat :8082 ──Flask 反代──► /fluffychat/  ← /chat 同源 iframe


一、日常启动

------------

1) 启动金格（必须 0.0.0.0，不要用 127.0.0.1）：

     venv\Scripts\python.exe -m flask run --host=0.0.0.0 --port=1000

   若 VS Code / Cursor 调试器仍绑 127.0.0.1，请改 launch 参数或改用上面命令重启。

2) 启动 Matrix（Synapse + FluffyChat）：

     cd matrix

     docker compose up -d

3) 打开聊天室：

     http://127.0.0.1:1000/chat

   （iframe 加载同源 /fluffychat/）

   选择「金格Pi」→ 用实训账号登录


二、对外根地址：domain.txt（推荐）与环境变量

--------------------

  穿透根会变：请把当前穿透根写进仓库根 **domain.txt**（一行 URL，无尾斜杠、
  无路径）。Flask **每次启动**都会读；缺失或空文件回退本机默认。

  优先级：
    1) 环境变量 PUBLIC_BASE_URL（或旧名 OIDC_PUBLIC_BASE）
    2) 仓库根 domain.txt
    3) 默认 http://127.0.0.1:1000

  示例：复制 domain.txt.example → domain.txt，改成你的穿透根，例如：
     https://xxxx.ngrok-free.app

  domain.txt 已加入 .gitignore，不要把真实穿透 URL 提交进 git。
  本机开发可不建该文件，自动用 127.0.0.1:1000。

  Flask（python main.py）启动时由 auth_config 直接读 domain.txt，
  不依赖 start_with_domain.ps1 / .sh。

  其它可选环境变量：

  OIDC_ISSUER=http://host.docker.internal:1000
   仅 Synapse 容器内访问；穿透时勿改成穿透域名。

  MATRIX_SERVER_NAME=matrix.localhost

  OIDC_MATRIX_CLIENT_ID=jingepi-synapse

  OIDC_MATRIX_CLIENT_SECRET=change-me-synapse-oidc-secret

  AUTHLIB_INSECURE_TRANSPORT=1

  FLUFFY_PROXY_ENABLED=1
  FLUFFY_UPSTREAM=http://127.0.0.1:8082
  FLUFFY_PROXY_PATH=/fluffychat
  FLUFFY_URL=http://localhost:8082


二½、内网穿透

--------------------

根因：只在手机里填穿透地址不够。SSO / well-known / public_baseurl
仍指向 127.0.0.1 时，手机会跳回本机或 Client API 发现失败。

推荐流程（文件驱动，跨平台）：

1) 写穿透根到仓库根 domain.txt（见 domain.txt.example）：
     https://xxxx.ngrok-free.app
   （不要带 /fluffychat；优先 HTTPS）

2) 一键同步并启动（读 domain.txt → apply → recreate → Flask）：
     python start_with_domain.py
   或：
     python3 start_with_domain.py

   Windows 快捷：.\start_with_domain.ps1
   macOS/Linux 快捷：./start_with_domain.sh

   或分步：
     python matrix/apply_public_base.py
     cd matrix
     docker compose up -d --force-recreate synapse fluffychat
     python main.py
   （Flask 会从 domain.txt 读 PUBLIC_BASE_URL；须 0.0.0.0:1000）

3) 客户端 Homeserver URL = 穿透根（同上，不要 /fluffychat）

4) 自检：
     GET https://xxxx.ngrok-free.app/.well-known/matrix/client
     应见 "base_url": "https://xxxx.ngrok-free.app"

改 domain.txt 后怎么重启：
  - 只影响 Flask well-known / OIDC 浏览器 URL → 重启 Flask 即可
  - Synapse public_baseurl / FluffyChat defaultHomeserver 也要跟上 → 必须再跑
    apply_public_base，并对 synapse + fluffychat **force-recreate**。
    仅 docker compose restart 不够：Synapse 在启动时读 yaml。
    便捷：python start_with_domain.py（默认会 apply + recreate）


三、FluffyChat 同源反代

--------------------

- 默认 FLUFFY_PROXY_ENABLED=1：Flask 把 /fluffychat/* 转发到 FLUFFY_UPSTREAM

- /chat 的 iframe 使用相对路径 /fluffychat/（与金格同端口、同站点）

- 关闭反代：FLUFFY_PROXY_ENABLED=0，则回退到 FLUFFY_URL（跨源 iframe）

- 自检：浏览器打开 http://127.0.0.1:1000/fluffychat/ 应看到 FluffyChat（需上游 :8082 已起）


四、Cursor Simple Browser / Cookie

----------------------------------

- Cursor 内置 Simple Browser 对第三方 Cookie、Secure+SameSite=None（明文 HTTP）更严

- 同源 /fluffychat/ + 本地 Session 使用 Secure=False、SameSite=Lax，便于 HTTP 实训

- 若 iframe 内 SSO 仍失败：顶层打开 /fluffychat/ 完成 OIDC

- 仍不行时请改用本机 Chrome/Edge 打开 http://127.0.0.1:1000/chat

- 生产务必 HTTPS、去掉 skip_verification，并更换所有 change-me 密钥


五、其它说明

------------

- MXID localpart = 金格 users.id（uuid4.hex，32 位小写十六进制）；显示名 = 金格 username。
  Synapse enable_set_displayname=false / enable_set_avatar_url=false；
  sso.update_profile_information=true，每次 SSO 用金格用户名/头像同步。
  金格改用户名/头像时经 Synapse Admin API 即时同步。
  homeserver.yaml 已设 enable_authenticated_media: false（实训）。
  裂图修复后可重推：python -c "import synapse_admin; print(synapse_admin.sync_avatars_from_disk())"
  Admin token：首次自动注册 @jingepi-admin，缓存到 matrix/data/jingepi-admin.access_token；
  或设 SYNAPSE_ADMIN_ACCESS_TOKEN / 跑 matrix/bootstrap-admin.ps1。

- 实训隐藏停用账户：Flask 拦截 POST /_matrix/client/*/account/deactivate（403）。
  建群/建空间：仅金格角色 admin / super_admin 可 POST createRoom（非 is_direct）；
  普通 user 被 matrix_proxy 403；私聊 DM 仍允许。
  /api/matrix/capabilities 供客户端隐藏新建入口。

- 环境变量补充：
  SYNAPSE_REGISTRATION_SHARED_SECRET（默认与 homeserver.yaml 一致）
  SYNAPSE_ADMIN_ACCESS_TOKEN（可选，跳过自动注册）

- homeserver.yaml：discover: false，authorization_endpoint 用 PUBLIC_BASE_URL；
  token/jwks/userinfo 仍用 host.docker.internal；skip_verification: true 仅本地 HTTP

- 若 SSO 仍跳到 host.docker.internal：检查 Flask 是否仍绑 127.0.0.1，并
  docker compose restart synapse

- 若 SSO 仍跳到 127.0.0.1：检查 domain.txt / PUBLIC_BASE_URL /
  public_baseurl / authorization_endpoint，并 force-recreate synapse

同源 Synapse 反代（已默认开启）
--------------------------------
- FluffyChat / SSO / Client API 全部走 http://127.0.0.1:1000
- Flask 反代 /_matrix 与 /_synapse 到 127.0.0.1:8008
