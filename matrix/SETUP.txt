一、日常启动

------------

1) 启动金格（必须 0.0.0.0，不要用 127.0.0.1）：

     venv\Scripts\python.exe -m flask run --host=0.0.0.0 --port=1000

   若 VS Code / Cursor 调试器仍绑 127.0.0.1，请改 launch 参数或改用上面命令重启。

2) 启动 Matrix（含 Element）：

     cd matrix

     docker compose up -d

3) 打开聊天室：

     http://127.0.0.1:1000/chat

   （iframe 加载同源 /element/；也可点「在新标签打开聊天室」）

   选择「金格Pi」→ 用实训账号登录





二、对外根地址：domain.txt（推荐）与环境变量

--------------------

  穿透根会变：请把当前穿透根写进仓库根 **domain.txt**（一行 URL，无尾斜杠、
  无路径）。Flask **每次启动**都会读；缺失或空文件回退本机默认。

  优先级：
    1) 环境变量 PUBLIC_BASE_URL（或旧名 OIDC_PUBLIC_BASE）
    2) 仓库根 domain.txt
    3) 默认 http://127.0.0.1:1000

  示例：复制 domain.txt.example → domain.txt，改成你的穿透根，例如：
     https://xxxx.ngrok-free.app

  domain.txt 已加入 .gitignore，不要把真实穿透 URL 提交进 git。
  本机开发可不建该文件，自动用 127.0.0.1:1000。

  Flask（python main.py）启动时由 auth_config 直接读 domain.txt，
  不依赖 start_with_domain.ps1 / .sh。

  其它可选环境变量：

  OIDC_ISSUER=http://host.docker.internal:1000

   仅 Synapse 容器内访问；穿透时勿改成穿透域名。

  MATRIX_SERVER_NAME=matrix.localhost

  OIDC_MATRIX_CLIENT_ID=jingepi-synapse

  OIDC_MATRIX_CLIENT_SECRET=change-me-synapse-oidc-secret

  OIDC_MATRIX_REDIRECT_URIS=…

   默认已含 {PUBLIC_BASE_URL}/_synapse/client/oidc/callback；
   一般不必手写。

  AUTHLIB_INSECURE_TRANSPORT=1

  ELEMENT_PROXY_ENABLED=1

  ELEMENT_UPSTREAM=http://127.0.0.1:8081

  ELEMENT_PROXY_PATH=/element

  ELEMENT_URL=http://localhost:8081


二½、内网穿透（手机 Element 连不上时）

--------------------

根因：只在手机里填穿透地址不够。SSO / well-known / public_baseurl
仍指向 127.0.0.1 时，手机会跳回本机或 Client API 发现失败。

推荐流程（文件驱动，跨平台）：

1) 写穿透根到仓库根 domain.txt（见 domain.txt.example）：
     https://xxxx.ngrok-free.app
   （不要带 /element；优先 HTTPS）

2) 一键同步并启动（读 domain.txt → apply → recreate → Flask）：
     python start_with_domain.py
   或：
     python3 start_with_domain.py

   Windows 快捷：.\start_with_domain.ps1
   macOS/Linux 快捷：./start_with_domain.sh
   （.ps1 / .sh 只调 Python，核心逻辑在 start_with_domain.py）

   或分步：
     python matrix/apply_public_base.py
     cd matrix
     docker compose up -d --force-recreate synapse element
     python main.py
   （Flask 会从 domain.txt 读 PUBLIC_BASE_URL，不依赖 .ps1；须 0.0.0.0:1000）

3) 手机 Element Homeserver URL = 穿透根（同上，不要 /element）

4) 自检：
     GET https://xxxx.ngrok-free.app/.well-known/matrix/client
     应见 "base_url": "https://xxxx.ngrok-free.app"

改 domain.txt 后怎么重启：
  - 只影响 Flask well-known / OIDC 浏览器 URL → 重启 Flask 即可
    （python main.py 或 python start_with_domain.py --skip-compose --skip-apply）
  - Synapse public_baseurl / Element base_url 也要跟上 → 必须再跑
    apply_public_base，并对 synapse（及 element）**force-recreate**。
    仅 docker compose restart 不够：Synapse 在启动时读 yaml。
    便捷：python start_with_domain.py（默认会 apply + recreate）

常见坑：
  - Android 明文 HTTP 被拦 → 用 HTTPS 穿透
  - ngrok 浏览器警告页 → 先用浏览器点一次 Visit Site
  - OIDC redirect_uri 未白名单 → 写好 domain.txt 后重启 Flask
    （默认会加入穿透回调）
  - Cookie Secure / 明文 HTTP：本地开发会去 Secure；HTTPS 穿透一般可登录
  - 改了 homeserver.yaml 后未 recreate synapse → SSO 仍跳 127.0.0.1





三、Element 同源反代

--------------------

- 默认 ELEMENT_PROXY_ENABLED=1：Flask 把 /element/* 转发到 ELEMENT_UPSTREAM

- /chat 的 iframe 使用相对路径 /element/（与金格同端口、同站点）

- 关闭反代：ELEMENT_PROXY_ENABLED=0，则回退到 ELEMENT_URL（跨源 iframe）

- 自检：浏览器打开 http://127.0.0.1:1000/element/ 应看到 Element（需上游 :8081 已起）





四、Cursor Simple Browser / Cookie

----------------------------------

- Cursor 内置 Simple Browser 对第三方 Cookie、Secure+SameSite=None（明文 HTTP）更严

- 同源 /element/ + 本地 Session 使用 Secure=False、SameSite=Lax，便于 HTTP 实训

- 若 iframe 内 SSO 仍失败：点「在新标签打开聊天室」（顶层导航更易完成 OIDC）

- 仍不行时请改用本机 Chrome/Edge 打开 http://127.0.0.1:1000/chat

- 生产务必 HTTPS、去掉 skip_verification，并更换所有 change-me 密钥





五、其它说明

------------

- MXID localpart = 金格 users.id（uuid4.hex，32 位小写十六进制），形如
  @a1b2c3d4e5f6...（32 位）:matrix.localhost；显示名 = 金格 username。
  Synapse enable_set_displayname=false / enable_set_avatar_url=false，
  客户端不可改显示名与头像；
  sso.update_profile_information=true，每次 SSO 登录用金格用户名同步显示名，
  并用 OIDC picture（绝对 URL，host.docker.internal）尽量同步头像
  （OIDC userinfo 每次从 DB 读当前 username / 头像路径，非缓存）。
  金格「用户设置」改用户名时，Flask 另调 Synapse Admin API
  PUT /_synapse/admin/v2/users/@<id>:matrix.localhost {displayname}
  即时更新，无需重新登录 Matrix。
  金格改头像时：Flask 读本地 users/<id>/avatar.* → POST 媒体库得 mxc://
  → Admin API 设 avatar_url，Element 刷新后两边一致。
  注意：Synapse 默认认证媒体会使 /_matrix/media/v3/* 对新媒体 404；
  homeserver.yaml 已设 enable_authenticated_media: false（实训）。
  裂图修复后可重推：python -c "import synapse_admin; print(synapse_admin.sync_avatars_from_disk())"
  Element 设置页隐藏「显示名称」与改头像（lab-suppress）；服务端仍同步 displayname。
  Admin token：首次自动用 registration_shared_secret 注册 @jingepi-admin，
  缓存到 matrix/data/jingepi-admin.access_token；或设环境变量
  SYNAPSE_ADMIN_ACCESS_TOKEN / 跑 matrix/bootstrap-admin.ps1。
  Element 无单独「隐藏改名/改头像」UIFeature，以服务端禁用 + lab-suppress 为准。
  实训强制主题 custom-金格Pi（default_theme + setting_defaults.theme，
  use_system_theme=false）；Element 1.12 无 UIFeature.themeSetting，
  lab-suppress-e2ee-nags.js 隐藏外观页主题选择器并写回 localStorage；
  lab-jingepi-theme.css + config compound 对齐金格炭黑/金表面与 Noto Sans SC，
  并覆盖 Compound accent / primary CTA 默认绿为 #f0b90b。
  实训隐藏「停用账户」与「个人信息」相关 UI：UIFeature.deactivate /
  identityServer / thirdPartyId=false；Synapse 无官方关停用 API 的配置，
  Flask :1000 反代拦截 POST /_matrix/client/*/account/deactivate（403）。
  同步拦截 /_matrix/client/*/room_keys/*（密钥备份创建/读写，403）。
  建群/建空间：仅金格角色 admin / super_admin 可 POST createRoom（非 is_direct）；
  普通 user 被 matrix_proxy 403；私聊 DM（is_direct）仍允许。Element 经
  /api/matrix/capabilities 隐藏新建房间/空间入口。

- 环境变量补充：
  SYNAPSE_REGISTRATION_SHARED_SECRET（默认与 homeserver.yaml 一致）
  SYNAPSE_ADMIN_ACCESS_TOKEN（可选，跳过自动注册）

- 迁移注意：已有 Matrix 账号通过 OIDC sub（金格 id）绑定，再次 SSO 仍进旧
  MXID（形如 @u<截断uuid>:…），不会自动改成新 localpart。仅新注册用户为
  @<完整32位hex>:matrix.localhost。若要统一新格式：管理员删除旧 Matrix 用户
  后重新 SSO，或 docker compose down -v 清空 synapse-pg 后重建实训环境。

- Element 已配置 CSP frame-ancestors，允许被金格页面 iframe

- homeserver.yaml：discover: false，authorization_endpoint 用 PUBLIC_BASE_URL

  （本机默认 127.0.0.1；穿透用 apply_public_base.py），
  token/jwks/userinfo 仍用 host.docker.internal；skip_verification: true 仅本地 HTTP

- 若 SSO 仍跳到 host.docker.internal：检查 Flask 是否仍绑 127.0.0.1，并

  docker compose restart synapse

- 若 SSO 仍跳到 127.0.0.1：检查 domain.txt / PUBLIC_BASE_URL /
  public_baseurl / authorization_endpoint 是否已改成穿透根，并
  force-recreate synapse（见 python start_with_domain.py）

- 镜像拉取困难时可配 registry-mirrors（Docker Desktop / daemon.json）
